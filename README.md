# Substation Tower: Edit Site manual

This manual explains every option in the **Edit site** panel. Only the owner sees **Edit site**. Visitors see the public site.

## 1. Opening the editor

1. Open the site while signed in as the owner.
2. Click **Edit site** in the top menu (on a phone, open the menu first).
3. The panel slides in from the right. Pick a tab along the top: Works, News, Gallery, Profile, Video, Schedule, Shop, Layout, Site, Look.

Changes show on the page straight away, but they are **not public until you click Publish changes**.

Anything saved as a draft (Published unticked) shows to you only, with a "Draft" mark.

### Collapsing boxes

Every box in the editor (a heading box, a track, an extra cover, an award, an event, a section's settings and so on) has a header row with a ▾ arrow and a short summary, usually its title. Click the header to collapse the box to that single row, and click again to open it. **Collapse all boxes** and **Expand all boxes** at the top of the panel do every box in the view at once. Collapsing a heading box also hides the tracks inside it. In the **Site** tab, tick **Collapse all boxes in every section** to start every box in every tab collapsed (open them one at a time); untick it to open them all again. Boxes stay collapsed while you edit, and open again when you reload the page.

## 2. Buttons at the bottom of the panel

| Button | What it does |
| --- | --- |
| **Publish changes** | Saves everything and makes it live. Greyed out when nothing has changed. |
| **Discard** | Throws away all unpublished changes and goes back to the last published version. |
| **Preview as public** | Shows the site exactly as a visitor sees it (no drafts, no editing buttons). Click **Exit preview** (bottom left) to return. |
| **Arrange on page** | Puts move, settings and hide buttons on every section of the page you are viewing. See section 13. |
| **Download site file** | Saves the whole site as one `index.html` file with pictures included, for uploading to your own web host. Only published works, news, events and products are included. |
| **Close** (top right) | Closes the panel. Unpublished changes stay until you publish or discard. |

## 3. Works

A *work* is an album, a poem collection or a book. The Works tab lists them all.

- **Views**: the chips at the top switch between **All**, **Discography**, **Anthology** and **Bibliography**, each with a count. A view lists only that section, shows the collection name beside each work, and **New work** creates a work in that section. **↑ / ↓** moves a work past the next work in the same view.
- **New work**: creates a draft at the top of the list.
- **Edit**: opens that work's form.
- **↑ / ↓**: changes the order. The first three published works appear as *Latest works* on the home page, and the order here is the order in the Library.

### Work form

| Field | Notes |
| --- | --- |
| **Title** | Name of the work. |
| **Section** | Discography (albums and songs), Anthology (poems) or Bibliography (books). It decides which Library section shows it. |
| **Year** | Free text, for example `2026` or `19.06.2026`. |
| **Format** | Optional label such as Studio album, Lyrics, Novel. |
| **Catalogue number** | Optional. In the Substation design each published work shows a number such as ST-001 above its title. Leave this empty for the automatic number, or type your own (for example `TOU-09`). |
| **Collection** | Optional. Groups works inside their section under a heading. Give one set of poems the collection `Anthology 1` and another set `Anthology 2`, and the Anthology page and the Library show a heading for each set, in number order. Works with no collection appear last under *Other*. The box suggests names you already used. It works the same for albums and books. |
| **Genre** | Optional. Pick a suggestion (Pop, Rock, Folk, Free verse, Fiction and more) or type your own. Separate several genres with commas. It shows in the line above the title and on cards. |
| **Short line** | First line, tagline or blurb. Shown on cards and under the title. |
| **Poem, lyrics or full text** | The main text. For poems every line break and blank line is kept as typed. |
| **List heading** | Name of the list, for example Tracklist, Poems, Chapters. |
| **List style** | Rows, Two columns or Compact. |
| **Link to listen or buy** | Adds a button on the work page. |
| **Cover or picture** | Uploads the main cover. Works without a picture show the Tower placeholder. |
| **Cover fit** | Any picture size is shrunk to fit inside the square cover box without cropping. Empty space around a non-square picture shows the panel colour. |
| **Name of this cover** | Optional name for the main cover, for example Standard. |
| **+ Add another cover** | Adds an extra cover (for example Deluxe, Alternate, Vinyl) with its own picture and name. Use ↑ ↓ to reorder and Remove to delete. On the work page the covers appear as small pictures under the main cover, and visitors click one to see it larger. Cards and the home banner use the main cover. Extra covers also appear in the Gallery. |
| **Feature on the home page** | The featured work appears in the home Hero banner. If none is ticked, the newest album is used. |
| **Published** | Untick to keep it as a draft. |
| **Delete work** | Asks you to confirm. |

### Tracklist (list in a work)

In the editor the list is arranged in **boxes**. Each heading (for example `Standard Edition`, `Disc 2`, `Bonus tracks`) is one box, and the tracks that belong to it sit inside that box. Tracks placed before the first heading go in a box called "Tracks without a heading".

- **Add heading**: starts a new box at the bottom of the list.
- **+ Add track to this box**: adds a track at the end of that box.
- **Add to list**: adds a track to the end of the last box.
- **↑ Move box / ↓ Move box**: moves a heading together with all its tracks.
- **Remove heading**: deletes the heading only. Its tracks join the box above.
- For each track: **Title**, **Time or note** (for example `3:42`), **Tag** (for example `Title track`), **Listen link** (shows a ▶ button), **Single cover**, **Lyrics**, and the buttons ↑ ↓ Duplicate Remove.

On the public Work page each heading is one box with its own track count and running time, and track numbers keep counting across boxes. The overall track count and total time show beside the list heading.

### Awards (under the tracklist)

Under **Awards**, click **+ Add award** for each ceremony. A ceremony has an **Award name**, a **Trophy design**, an optional **Note** and an optional **Own trophy or badge picture** (which replaces the design). Inside it, click **+ Add category** for each category. Every category has its own **Category**, **Result** (Winner, Nominee, Finalist, Honoree, Certified, Record), **Year** and **Presented by**, so one ceremony can hold wins and nominations from different years. **Remove category** deletes one; ↑ ↓ reorder ceremonies. **Awards heading** renames the section (default *Highlights*).

**Trophy designs:** Tower trophy, Gold cup, Laurel honour, Record award, Platinum disc, Star award and Medal of honour. They are drawn in your site colours: the structure follows **Tower placeholder** and the accents follow **Tower wires** in Look.

On the Work page the section is an **archive**: a centred heading with a small tower badge, a tally such as "3 wins · 6 nominations", a rule, then the awards in columns. Each ceremony is a bold heading like `2027: GRAMMY AWARDS` with its categories listed underneath, and winners marked with a star. Entries with the same award name and year are grouped under one heading automatically, so you can add one entry per result. In Layout, Work page, **Awards and recognition** can be moved, hidden, switched between **Archive**, **Cards** and **List**, and given a column count.

**Single cover.** Upload a picture for any track. It shows as a small thumbnail in the tracklist and as a larger cover on the track's own page, above the lyrics. A track without a single cover uses the cover of the work. Single covers also appear in the Gallery.

Every track title links to its own **track page**, with the cover, a Listen button, the lyrics and previous and next track links. Tracks with lyrics get a small *Lyrics* tag.

### Paste a tracklist

Paste many tracks at once into the **Paste a tracklist** box and click **Add pasted lines**. One track per line. These all work:

```
# Disc 1
Substation Tower | 3:42 | Title track
1. Wildfire - 3:15
Static Prayer 4:02
Last Witness (5:01)
Siren Song | 2:58 | https://example.com/listen
```

- A line starting with `#`, written as `[Disc 2]`, or ending with a colon becomes a heading.
- A time (`3:42`), a tag and a link can come in any order on a `|` separated line.
- Tick **Replace the current list** to clear the existing list first.

## 4. News

Announcements shown on the News page and as *Latest news* on the home page.

- **New news item**, then **Edit**.
- Fields: **Headline**, **Date** (newest date shows first), **Text**, **Picture** (optional), **Published**.
- Items without a picture show the Tower placeholder when shown as cards.
- **Delete news item** asks you to confirm.

## 5. Gallery

The Gallery page fills itself with every picture on the site: works, track single covers, news and your profile photo.

- **Add pictures**: upload extra pictures (several at once).
- Each added picture has a **Caption** and a **Remove** button.
- Click a picture on the page to open the full-size viewer with previous and next.

## 6. Profile

- **Profile picture**, **Headline**, **Biography** (blank line starts a new paragraph).
- **Details**: label and value pairs, for example Based in, Instruments. **Add a detail**, **Remove**.
- **Contact and listen links**: label and value pairs such as Spotify, Instagram, an email address. A value starting with `https://` becomes a link. These also show in the footer.

## 7. Video

- **Add video link**: **Title**, **Link** (YouTube or any site), **Note**.
- Only entries with a link appear. Videos open on their own site in a new tab.

## 8. Schedule

- **Add event** and **Add music release**: **Date**, **Time**, **Place**, **Title**, **Link** (optional), **Published**, **Remove**.
- Published events split automatically into **Upcoming** and **Past** by date.
- Two buttons: **Add event** and **Add music release**. Each entry has a **Type** (Show, Music release, Other) and an optional **Time**.
- **Music release**: pick one of your works from **Release (pick from your works)**. If **Title** is empty the work title is used, and a **View release →** button links to the work page. Use **Label or platform** for the label or streaming service, and **Listen link** for a link.
- Releases show a bold *Music release* label on the public page.

## 9. Shop

A store-style page with a promo strip, category tiles, search, filters and product pages. Buying happens on the link you give each product, because the site has no checkout.

- **New product**, then **Edit**. **↑ / ↓** orders products.
- Product fields: **Product name**, **Price**, **Sale price** (shows the old price crossed out), **Category**, **Collection**, **Badge** (for example New, Limited, Signed), **Description**, **Buying link**, **Picture**, **In stock** (untick for a Sold out label), **Published**.
- **Duplicate** copies a product as a draft. **Delete product** asks you to confirm.
- Products without a picture show the Tower placeholder.

### Shop settings

| Setting | Notes |
| --- | --- |
| **Currency symbol** | For example `$`, `RM`, `£`. |
| **Promo strip** | A message bar at the top of the Shop page with an optional **button label**, **button link** and **Countdown ends** date and time. Leave the message empty to hide it. |

Visitors can search, sort (price low to high, high to low, name A to Z), pick a category, pick a collection, and tick *On sale* or *In stock*. Categories and collections for those filters come from your products, so typing a new category on a product creates it.

To control the Shop page layout (move, hide, add a **Product shelf** to any page), use the Layout tab.

## 10. Layout

Every page is a stack of sections. Layout lets you rearrange them and add your own.

1. Choose a **Page**: Home, Shop, Library, Discography page, Anthology page, Bibliography page, Gallery, Profile, News, Video, Schedule, or **Work page** (one layout shared by every work page).
2. Each section has **Settings**, **↑**, **↓** and **Hide / Show**.

### Settings available for every section

| Setting | Choices |
| --- | --- |
| **Width** | Narrow, Medium, Wide |
| **Alignment** | Left, Centre, Right |
| **Spacing** | Tight, Normal, Loose |
| **Overall scale** | 80%, 90%, 100%, 115%, 130% (scales text and pictures together) |

### Settings for particular sections

| Section | Extra settings |
| --- | --- |
| **Hero** (Home) | **Style**: Latest release, Name and artwork, or Both. Title size and tagline size sliders (each with an Auto button), title case, weight, italic or upright, letter spacing, line spacing, title colour. Picture: show or hide, upload your own, width slider, position (left, right, above). **Reset words and picture**. |
| **Latest news** | How many, Style (Rows or Cards), Columns |
| **Latest works** | How many, Style (Covers or Contents), Columns |
| **Library, Discography, Anthology, Bibliography sections** | Style (Follow Look tab, Contents, Covers), Columns |
| **Shop sections** | Columns, product list options, filter bar style (full, search only, none) |
| **Gallery and Video grids** | Columns |
| **Photo and biography** (Profile) | Photo beside text or above |
| **Cover picture** (Work page) | Automatic, above the text, beside the text |
| **Tracklist** (Work page) | **Separator line above the list**: Hide (default) or Show |

The Hero is the large banner at the top of the Home page.

### Add your own sections

Use **+ Text section**, **+ Picture**, **+ Spacer** (and **Product shelf** on shop-enabled pages) to add a section to any page.

- **Text section**: Plain, Banner (dark panel) or Picture beside. Heading, text, two buttons (label and link), optional picture.
- **Picture**: upload, caption, optional link.
- **Spacer**: blank space or a thin line.
- **Product shelf**: shows products from the Shop. Choose a heading, a category, how many, and columns.
- Every custom section can be **renamed, duplicated, moved, hidden, resized and deleted** (Delete asks you to confirm).

**Reset this page** puts the page back to the default sections. It removes custom sections on that page.

## 11. Site

- **Catalogue prefix**: the letters in automatic catalogue numbers (ST-001). **Hide catalogue numbers** removes them. Numbers count down by default (the first work in the Works tab has the highest number, the last has 001); tick **Count upwards** to number from 001 at the top. Moving a work changes its number; type a fixed number on the work to stop that.
- **Name**, **What you make** (the small line above the name), **Tagline**, **Footer line**.
- **Page and section names**: rename pages and headings (Home, Library, Gallery, Shop, Discography, Bibliography, Latest news and so on). **Restore default names** resets them.

## 12. Look

| Option | Notes |
| --- | --- |
| **Design** | Literary or Substation (original). Choosing one resets the accent colour and typeface to its own. |
| **Colours** | Each colour has a colour box and a hex box. Pick with the box or type a code such as `#C4471B`. **Accent colour** colours buttons, links, badges and highlights. **Page background**, **Text colour** and **Cards and panels** apply to the light theme only; the dark theme keeps its own colours. **Tower placeholder** and **Tower wires** colour the placeholder picture. Leave a field empty (Auto) to follow the design. **Reset colours to automatic** clears all of them except the accent. |
| **Typeface** | Literary, Stage, Typewriter, Signage. |
| **Heading font** and **Body font** | Override the typeface for headings or body text separately. |
| **Text size** | Small, Normal, Large, Extra large. |
| **Site width** | Narrow, Normal, Wide. |
| **Corners** | Design default, Square, Soft, Round. |
| **Header** | Name on the left, or centred. |
| **Reset all of the above** | Clears the colour, font, size, width, corner and header overrides. |
| **Library layout** | Contents (list) or Covers (grid), used wherever a section is set to Follow Look tab. |
| **Default theme** | Auto, Light or Dark for new visitors. Visitors can still switch with the **Theme** link in the menu. |

### The Tower placeholder

Every empty picture box (work covers, product pictures, news cards, product page, category tiles) shows a line drawing of a transmission tower. Its colour follows the site colours: the tower uses a soft text colour and the wires use the accent. Override them with **Tower placeholder** and **Tower wires** in Look.

A standalone copy of the drawing is supplied with this manual as `substation-tower.svg` and `substation-tower.png`.

## 13. Arrange on page

1. Click **Arrange on page** (in the panel footer, or in Layout).
2. Open any page. Every section gets a small toolbar: **↑ ↓ Settings Hide/Show**. Hidden sections appear as dashed boxes so you can show them again.
3. At the bottom of the page, an **Add a section** bar adds text, picture or spacer sections.
4. Click **Done arranging** (bottom left) when finished, then **Publish changes**.

## 14. Publishing, sharing and your own domain

- Publishing updates the page at its private link. The page is **private until you share it** from the **Share** menu of the page. Edit site always requires you to be the owner (or someone you gave edit access).
- To use your own domain (for example substationtower.net): click **Download site file**, then upload the `index.html` to a web host or static hosting service that serves your domain. Re-download and re-upload after later changes.
- Pictures are uploaded to the page's storage. The download embeds them in the file.
- If you edit the page in two places at once, the most recently published version wins, so avoid editing the same page from two sessions.

## 15. Tips and troubleshooting

- **Nothing shows on a page**: check the section is **Shown** in Layout, and the work, news item, event or product is **Published**.
- **Changes vanished**: they were not published. **Discard** also removes them.
- **Pictures will not upload**: use PNG, JPEG, WebP or GIF. Large phone photos are shrunk automatically to 2400 px before uploading. HEIC photos may not work on every phone; switch the camera to JPEG or take a screenshot of the photo.
- **Hero words break across lines**: lower the Title size slider in Layout, Home, Hero, or choose a wider Width.
- **Hex code not accepted**: it must be six characters, for example `#2D6CB0`.
- **A colour looks wrong in dark theme**: background, text and card colours are light-theme only. Switch Theme to Light to check them.

## Newer options

**Award result symbols.** Every result has its own symbol, shown in the editor menu and on the page: ★ Winner, ◇ Nominee, ◈ Finalist, ❖ Honoree, ✔ Certified, ● Record.

**Schedule headings.** The two headings on the Schedule page, *Upcoming* and *Past*, are filled in automatically by comparing each event's date with today's date. Rename them under Edit site, Site, in the Schedule: upcoming heading and Schedule: past heading boxes.

**Library sections (Site tab).** Under *Library sections*, click **+ Add library section** and type a name (for example Essays or Films). It gets its own page, its own block in the Library page (move or hide it in Layout), and a choice in every work's **Section** menu and in the Works tab views. Tick *Show text as verse* to keep line breaks. **Remove section** moves its works back to Anthology. Layout, Custom section pages sets the layout of those pages.

**Custom fields.** Works, news posts, events, videos and shop products each have a **Custom fields** box. Click **+ Add custom field** and type your own Label and Value (for example Producer: Name). They show on the public page for that entry.

**Release date and catalogue order.** Each work has a **Release date** (it replaces the old Year box). Under Site, *Order of works* chooses how everything is ordered: *Works tab order* (the bottom of the list in Edit site, Works is the oldest and gets ST-001; moving up is newer) or *Release date* (sorted automatically). Home, the Library, catalogue numbers and the Previous and Next links on a work page all follow this order, so Next from ST-001 is ST-002. Numbers run across all sections together. You can still type your own number on any work.

**Award categories.** Each award can hold several categories, each with its own result, year and presented-by, and ↑ ↓ buttons to reorder them.

**Collapse all boxes.** Under Site, *Editor preferences*, tick the box to start every box in Edit site collapsed.

**Menu bar stays visible (Look, then Menu bar when scrolling).** The top menu now stays at the top of the screen while visitors scroll, on desktop and phones. Choose *Scrolls away* for the old behaviour. In Edit site, each section heading also stays at the top of the panel while you scroll that section.

**Scheduled posting (Publish on).** Works, News, Shop products and Schedule events each have *Publish on (optional)* under Published. With Published ticked and a date and time set, the item stays hidden from visitors until then and appears by itself, even for visitors who already have the page open. You still see it, labelled Scheduled. Scheduled works get no catalogue number until they go live. *Clear date* removes the schedule. Times use the time zone of the device you set them on. The hiding happens in each visitor's browser, so the item's text is still inside the page file: do not schedule anything secret.

**Countdown pop-up (Site, Countdown pop-up).** A window that opens when a visitor arrives, counting down days, hours, minutes and seconds.
- *Show the pop-up to visitors*: master switch.
- *Counts down to*: A date I choose (set Countdown ends), or My next scheduled post (the nearest future Publish on date; it moves on to the next one by itself, and can hide the item's name).
- *Heading, Message, Button label and link*: the button is optional, for example Pre-save.
- *Show again*: Every visit, Only once per device, or Every page load. *Wait before showing*: 0 to 30 seconds.
- *Preview pop-up* shows it to you at once. It closes with Close, Escape or a click outside, and disappears when the time passes. It does not pop up on its own while the Edit site panel is open.
